# 🚀 Jorbites v3.4.3 ja és aquí!

Ens complau anunciar el llançament de Jorbites v3.4.3! Aquesta versió es centra en millores de rendiment mitjançant l'optimització d'imatges per a dispositius mòbils, la modularització de components extreient els passos de receptes, correccions de qualitat de codi per a dependències exhaustives de React, resolució d'incidències de React Doctor i actualitzacions de documentació.

## ✨ Funcionalitats i optimitzacions de rendiment

- 🖼️ **Optimització d'imatges**: S'han optimitzat les imatges a tota l'aplicació, amb millores específiques per a dispositius mòbils per millorar la velocitat de càrrega i el rendiment.
- 🧩 **Components de passos de recepta**: S'han extret els passos de recepta en components dedicats per millorar la mantenibilitat i reutilització.

## 🐛 Qualitat de codi i correccions

- ⚛️ **Avís de dependències exhaustives de React**: S'ha resolt l'avís de dependències exhaustives en hooks de React.
- 🩺 **Incidències de React Doctor**: S'han corregit les incidències detectades per React Doctor a la base de codi.

## 📖 Documentació

- 📖 **Notes de versió v3.4.2**: S'han afegit les entrades de blog del llançament de Jorbites v3.4.2 en tots els idiomes suportats.
