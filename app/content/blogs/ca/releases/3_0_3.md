# 🚀 Jorbites v3.0.3 ja és aquí!

Ens complau anunciar el llançament de Jorbites v3.0.3! Aquesta actualització se centra a actualitzar les dependències per seguretat, resoldre errors de referència/renderització en components de React i afegir documentació per al llançament anterior.

## 🛠️ Seguretat i qualitat de codi

- 🔒 **Actualització de seguretat de PostCSS**: S'ha actualitzat `postcss` de `8.5.18` a `8.5.23` per abordar vulnerabilitats a les dependències.
- ⚛️ **Errors de referències de React**: S'han corregit errors d'assignació/renderització de referències (ref) per evitar advertiments de sincronització d'estat i referències de hooks.

## 📝 Documentació i llançaments

- 📖 **Documentació del llançament de v3.0.2**: S'han afegit les publicacions de blog de llançament de Jorbites v3.0.2 en anglès, espanyol i català.
