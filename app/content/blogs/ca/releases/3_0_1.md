# 🚀 Jorbites v3.0.1 ja és aquí!

Ens complau anunciar el llançament de Jorbites v3.0.1! Aquesta actualització se centra a resoldre advertències clau d'accessibilitat, optimitzar les transicions, millorar el rendiment dels modals i eliminar les advertències de React/Next.js per oferir una plataforma més polida i fiable.

## ♿ Millores d'accessibilitat i interfície d'usuari

- 🏷️ **Modals accessibles**: S'han afegit etiquetes accessibles descriptives que faltaven (`control-has-associated-label`) als elements interactius, garantint una millor experiència per als usuaris de lectors de pantalla.
- 📭 **Advertiment de capçalera buida**: S'ha resolt l'advertiment de capçalera buida al client d'esdeveniments inserint text alternatiu ocult visualment dins de les capçaleres que envolten els carregadors d'esquelet.

## ⚡ Optimitzacions de rendiment i transicions

- 🔄 **Transicions refinades**: S'han reemplaçat les classes generals `transition-all` amb classes `transition` estàndard als components del Navbar i dels modals per limitar les animacions a les propietats visuals estàndard i evitar costosos refluxos de disseny.
- ⏱️ **Cerques ràpides en matrius**: S'han reemplaçat les operacions de cerca lineal en matrius dins de bucles en els components modals amb cerques altament eficients utilitzant `Set` / `Map`, minimitzant la sobrecàrrega de renderització.

## 🛠️ Qualitat de codi i correcció d'advertències de React

- 🔑 **Claus de qualificació d'estrelles estables**: S'ha corregit l'advertiment del linter `no-array-index-as-key` al component `StarRating` mitjançant l'ús de valors estables amb abast de mòdul en lloc d'índexs de matrius.
- 🌐 **Consistència d'URLs de metadades**: S'han resolt les advertències de consistència d'URLs de metadades a Next.js adoptant rutes relatives per a openGraph i URLs canòniques.
- 🧪 **Actualitzador d'estat impur**: S'ha corregit un patró d'actualitzador d'estat impur dins del component Navbar per alinear-se amb les millors pràctiques de React.
- 📝 **Documentació del llançament de v3.0.0**: S'han afegit les publicacions de blog de llançament de Jorbites v3.0.0 en anglès, espanyol i català.
