# 🚀 Jorbites v3.3.1 is here!

We are excited to announce the release of Jorbites v3.3.1! This patch release includes fixes for Gantt chart PNG export full-width rendering on small screens, keyboard accessibility enhancements for tooltips, UI warning resolutions in DraftCard, updated event schedule dates, and internal code maintenance.

## 🎨 UI & Accessibility Improvements

- 📊 **Gantt Chart PNG Export**: Fixed full-width rendering issue during PNG export on small screens.
- ⌨️ **Tooltip Keyboard Navigation**: Added keyboard event listeners to the tooltip container for improved accessibility.
- 📱 **DraftCard Styling**: Resolved `design-no-space-on-flex-children` warning in `DraftCard` layout.

## 📅 Events & Documentation

- 🍔 **Second Burger Championship**: Rescheduled the Second Burger Championship event to October 5, 2026.
- 📖 **v3.3.0 Documentation**: Added release blog post for Jorbites v3.3.0 across all supported languages.

## 🛠️ Refactoring & Code Quality

- 🔄 **Circular Dependencies**: Resolved circular dependencies across modules.
- 🧹 **Recipe Form State Cleanup**: Removed unused `checkIsCollaborativeSession` export from `useRecipeFormState`.
