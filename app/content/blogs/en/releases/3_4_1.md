# 🚀 Jorbites v3.4.1 is here!

We are excited to announce the release of Jorbites v3.4.1! This patch release brings improvements to recipe graph visualizations, resolves an iOS swipe gesture issue on Bite cards, updates event handlers and draft component logic, updates translations for meal planning, and includes documentation updates.

## ✨ Features & Design Enhancements

- 📊 **Recipe Graph Design**: Improved the design and visualization of recipe graphs.
- 🌐 **Translation Update**: Updated `meal_planner` translation key to "Plannings".

## 🐛 Bug Fixes & Code Quality

- 📱 **iOS Bite Card Swipe**: Fixed a bug affecting right-swipe gestures on Bite cards in iOS devices.
- 🛠️ **Draft Components**: Fixed `no-event-handler` warnings in draft components.
- ⌨️ **Tooltip Event Handler**: Renamed generic event handler names in the Tooltip component for better code clarity.
- 🎨 **Design Warnings**: Resolved `no-gray-on-colored-background` warnings across components.

## 📖 Documentation

- 📖 **v3.4.0 Documentation**: Added release blog post for Jorbites v3.4.0 across all supported languages.
