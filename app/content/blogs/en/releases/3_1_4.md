# 🚀 Jorbites v3.1.4 is here!

We are excited to announce the release of Jorbites v3.1.4! This update focuses on improving automated testing, fixing React rendering issues, scheduling new cooking events, resolving remaining react doctor warnings, and documenting our earlier release.

## 🛠️ Bug Fixes & Code Quality

- 🔄 **State Rerendering**: Resolved react state re-rendering issues to ensure smoother UI transitions.
- 🧑‍⚕️ **React Doctor Warnings**: Fixed remaining react doctor warnings to maintain optimal component performance and compliance.

## 🧪 Testing Improvements

- 🧪 **Jest Testing**: Enhanced automated Jest test suites and configurations.
- 🏎️ **E2E Test Optimization**: Optimized End-to-End (E2E) testing pipelines for faster execution and better reliability.

## 📅 Events & Community

- 🍽️ **New Cooking Events**: Added exciting new upcoming culinary and recipe events to our calendar.

## 📝 Documentation & Releases

- 📖 **v3.1.2 Documentation**: Added the release blog posts for Jorbites v3.1.2 in English, Spanish, and Catalan.
