# 🚀 Jorbites v3.0.0 is here!

We are thrilled to announce the release of Jorbites v3.0.0! This release marks a significant milestone, introducing more precise time-tracking categories, robust password policy controls, key API improvements, and critical state-management bug fixes to ensure a smoother, more reliable user experience.

## ⏱️ Better Time Distinction

- 📅 **Distinguishing Times**: Clarified and refined how preparation, cooking, and total times are defined and displayed across the platform, making it easier for home chefs to plan their culinary sessions.

## 🔒 Security & API Hardening

- 🛡️ **Secure Password Policy**: Strengthened user account security by implementing a more robust password policy, protecting credentials against modern security threats.
- 🔄 **RESTful API Semantics**: Updated the user image upload route, switching the HTTP method from `PUT` to `PATCH` to align with proper RESTful standards for partial resource updates.

## 🛠️ Technical Improvements & Bug Fixes

- ⚡ **No-Derived-State Fix**: Corrected a state management bug in the recipe creation and editing form where derived state was causing unexpected UI behavior or extra re-renders.
- 📝 **v2.9.1 Release Documentation**: Formally published the release blog posts for Jorbites v2.9.1 in English, Spanish, and Catalan.
