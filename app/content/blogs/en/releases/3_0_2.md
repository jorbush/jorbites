# 🚀 Jorbites v3.0.2 is here!

We are pleased to announce the release of Jorbites v3.0.2! This update focuses on resolving promise rejection warnings, improving push notifications authorization checks, resolving image aspect ratio warnings, and adding release documentation.

## 🛠️ Code Quality & Bug Fixes

- 🔒 **Safe Promise Handling**: Resolved a promise side-effect warning in `CertificateDownloadSection` by ensuring proper catch logic for async actions.
- 🖼️ **Image Aspect Ratio Warnings**: Addressed next/image aspect ratio warnings to optimize rendering and prevent layout shift console alerts.

## 🔔 Notifications & Documentation

- 🔒 **Push Notification Auth Checks**: Fixed authorization checks for push notifications to prevent unauthorized token lookup errors.
- 📝 **v3.0.1 Release Documentation**: Added the release blog posts for Jorbites v3.0.1 in English, Spanish, and Catalan.
