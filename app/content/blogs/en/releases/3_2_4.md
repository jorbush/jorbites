# 🚀 Jorbites v3.2.4 is here!

We are excited to announce the release of Jorbites v3.2.4! This update introduces component architecture abstractions, improvements to text parsing, comment box state management with a reducer, recipe form state warning fixes, and security hardening.

## 🧱 Component Architecture & State

- 🧩 **Feature Component Abstraction**: Abstracted new feature components for better modularity and maintainability.
- 💬 **Comment Box Reducer**: Added a reducer for comment box state management, improving predictability and state transitions.

## 📝 Parser & Recipe Form Optimizations

- 📋 **Single-Line List Parsing**: Enhanced `textParser` to parse single-line lists accurately.
- ⚡ **Parser Performance**: Refactored `.map().filter(Boolean)` to `.flatMap()` in `textParser` for cleaner single-pass processing.
- 🛠️ **Recipe Form Fixes**: Resolved state warnings in recipe form components.

## 🔒 Security & Documentation

- 🔑 **E2E Seed Security**: Removed hardcoded secret fallback in the E2E seed script.
- 📖 **v3.2.3 Documentation**: Published release blog posts for Jorbites v3.2.3 across all supported languages.
