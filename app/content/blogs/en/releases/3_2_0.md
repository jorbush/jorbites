# 🚀 Jorbites v3.2.0 is here!

We are excited to announce the release of Jorbites v3.2.0! This release introduces real-time collaborative recipe editing, cooked photo remakes, achievement quest badges, along with key UI, accessibility, and stability improvements.

## ✨ New Features

- 🤝 **Collaborative Recipe Editing**: Work together on recipes simultaneously with multi-user editing support and automatic step updates.
- 📸 **Cooked Photo Remakes**: Share and showcase remakes of dishes cooked by the community.
- 🏆 **Quest Badges**: Unlock badges by completing cooking quests and reaching community milestones.

## 🎨 UI & Accessibility Improvements

- ♿ **Accessibility Enhancements**: Added missing ARIA labels to CommentBox controls and improved smartphone input responsiveness by preventing automatic zoom on focus.
- 🎨 **Styling & Visual Polishing**: Updated PhotoLightbox background styling, fixed gray text contrast on colored backgrounds in RecipeModal, and migrated layout spacings to Tailwind gap utilities in CommunityGallery.

## 🛠️ Bug Fixes & Refactoring

- ⚡ **Hydration & URL Fixes**: Resolved error display hydration mismatches and fixed link routing issues.
- 🧹 **Code Cleanups**: Utility refactorings and cleanup, including size shorthand utilities and export optimizations.

## 📝 Documentation

- 📖 **v3.1.4 Documentation**: Published release blog posts for Jorbites v3.1.4 in English, Spanish, and Catalan.
