# 🚀 Jorbites v3.2.2 is here!

We are excited to announce the release of Jorbites v3.2.2! This update includes new end-to-end tests for collaborative recipes, CI pipeline enhancements, rescheduled event dates, translation fixes, and documentation updates.

## 🧪 Testing & CI

- 🧪 **Collaborative Recipes E2E Tests**: Added end-to-end tests for collaborative recipe workflows to ensure seamless multi-user cooking experiences.
- ⚡ **CI Pipeline Improvements**: Enhanced E2E testing workflows in continuous integration for higher reliability and stability.

## 📅 Events & Translations

- 🗓️ **Catalan Recipes Event**: Rescheduled event dates for the Catalan Recipes event to September 10–12.
- 🌐 **Event Translations**: Fixed translation keys and display logic for events across supported languages.

## 📝 Documentation

- 📖 **v3.2.1 Documentation**: Published release blog posts for Jorbites v3.2.1 in English, Spanish, and Catalan.
