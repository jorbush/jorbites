# 🚀 Jorbites v3.7.0 is here!

We are thrilled to announce the release of Jorbites v3.7.0! This release introduces the new "Remix / Fork Recipe" feature for collaborative cooking with author notifications and level progression, seamless view transitions for recipe browsing, a built-in PWA installation guide, localized quest timestamps, and key performance and dependency upgrades.

## 🍳 Recipe Remixing & Collaborative Cooking

- 🔀 **Remix / Fork Recipes**: Cooks can now fork existing recipes to create their own spin, maintaining collaborative culinary attribution.
- 🔔 **Remix Notifications & Level Progression**: Authors receive real-time notifications when their recipes are remixed, alongside author level updates.
- ⏱️ **Request Timeouts**: Added `AbortSignal` timeouts to notification and level update requests to avoid hanging operations.

## ✨ Visual Polish & View Transitions

- 🎬 **View Transitions**: Integrated smooth view transitions between recipe cards and recipe detail pages for an app-like browsing feel.
- 🕒 **Localized Quest Timestamps**: Quest cards now format and display relative time strings in the active user locale.

## 📱 Progressive Web App (PWA) Enhancements

- 📖 **PWA Installation Guide**: Added clear, platform-specific installation instructions to the footer.
- 👁️ **Smart Visibility**: Automatically hides the installation guide when the app is already running in standalone/installed mode.

## 📦 Dependencies & Documentation

- 📦 **Dependency Updates**: Upgraded Vite to `6.4.5` and `i18next-http-backend` to `4.0.4`.
- 📖 **v3.6.0 Documentation**: Added release blog posts for Jorbites v3.6.0 across all languages.
