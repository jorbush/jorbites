# 🚀 Jorbites v3.2.1 is here!

We are excited to announce the release of Jorbites v3.2.1! This update includes stability fixes for iOS devices, enhancements to collaborative recipe cooking, translation updates for quests, interface refinements, and documentation updates.

## 🛠️ Bug Fixes & Improvements

- 📱 **iOS & Clipboard Fixes**: Fixed toast display issues on iOS devices as well as clipboard copying functionality across platforms and iOS specifically.
- 🧑‍🍳 **Collaborative Cooking**: Fixed collaborative recipe cooking functionality to ensure smooth real-time cooking sessions.
- 🌐 **Translations**: Corrected quests translations across supported languages.

## 🎨 UI & Cleanups

- 🖼️ **Community Gallery**: Cleaned up the interface by removing the community gallery section.

## 📝 Documentation

- 📖 **v3.2.0 Documentation**: Added release blog posts for Jorbites v3.2.0 in English, Spanish, and Catalan.
