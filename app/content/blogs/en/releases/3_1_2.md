# 🚀 Jorbites v3.1.2 is here!

We are excited to announce the release of Jorbites v3.1.2! This update focuses on resolving various layout issues, improving accessibility, optimizing planning state initialization, preventing potential memory leaks, and cleaning up unused exports.

## 🛠️ Code Quality & Bug Fixes

- ♿ **Accessibility & Gantt Grid**: Fixed the `RecipeGanttGrid` accessibility warning.
- 📐 **Tailwind Styling**: Resolved several `design-no-redundant-size-axes` warnings across components.
- 🧹 **Unused Exports**: Removed unused default exports from the `RecipeGantt` files to keep imports clean.
- 🔄 **Event Handlers**: Corrected the event handler proxy issue.
- 💾 **Memory Leak Prevention**: Added code to revoke the object URL in the Export Calendar modal, ensuring browser resources are freed up correctly.
- ⚡ **State Optimization**: Optimized the `isSaved` state initialization within the `usePlanningState` hook for better performance.
- 🖼️ **Logo Aspect Ratio**: Fixed the logo aspect ratio to prevent distorting visual elements.

## 📝 Documentation & Releases

- 📖 **v3.1.1 Documentation**: Added the release blog post for Jorbites v3.1.1.
