# 🚀 Jorbites v2.9.1 is here!

We are excited to announce the release of Jorbites v2.9.1! This version focuses heavily on security auditing, database hardening, API protection, and code refactoring to keep Jorbites fast, secure, and modern.

## 🔒 Security & Hardening

- 🔑 **Password Reset Security**: Strengthened database storage by hashing password reset tokens securely via SHA-256 before carrying out database queries or updates.
- 🛡️ **Access Control & API Security**:
    - Secured the Planning GET endpoint with strict private planning access controls to prevent unauthorized data exposure.
    - Implemented a robust fix for the image proxy endpoint to eliminate Server-Side Request Forgery (SSRF) vulnerabilities.
    - Added comprehensive rate-limiting across endpoints to guard against abuse and denial-of-service attempts.
- 🍪 **Session & Configuration Hardening**:
    - Configured explicit `maxAge` and `updateAge` session settings in NextAuth, and pruned unused JWT claims to secure and minimize client cookies.
    - Injected Strict-Transport-Security (HSTS) and restrictive Permissions-Policy headers in `next.config.js`.
    - Moved the VAPID contact email config dynamically into environment variables (`VAPID_EMAIL`) with automatic mailto scheme prefixing.
- 📝 **Security Audit & Legal**: Completed the comprehensive Jorbites Security Audit for 2026 and updated our Terms and Conditions to reflect the latest security posture.

## 🛠️ Technical Improvements & Optimization

- ⚡ **React & Next.js Performance**:
    - Destructured hook methods like `push` from `useRouter` to optimize dependency graphs and facilitate React Compiler memoization.
    - Resolved React derived state and event-handling warnings in `NotificationPreferencesManager` to prevent unnecessary re-renders.
    - Replaced O(n) array loops with a static lookup `Set` inside notification preferences PATCH logic, achieving efficient O(1) membership tests.

## 🎨 UI, Styling & Motion

- 🌊 **Smooth Float Transition**: Replaced dated, tacky bounce animations with a highly professional, custom smooth-float deceleration transition on loader and action elements.
- 📐 **Tailwind Simplification**: Adopted modern Tailwind v3.4+ `size-4` utility shorthands to replace redundant width and height axes.
