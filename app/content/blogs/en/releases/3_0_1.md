# 🚀 Jorbites v3.0.1 is here!

We are pleased to announce the release of Jorbites v3.0.1! This update focuses on resolving key accessibility warnings, optimizing transitions, enhancing modal performance, and eliminating React/Next.js warnings to deliver a more polished and reliable platform.

## ♿ Accessibility & UI Enhancements

- 🏷️ **Accessible Modals**: Added missing descriptive accessible labels (`control-has-associated-label`) to interactive elements, ensuring a better experience for screen reader users.
- 📭 **Empty Heading Warning**: Resolved the empty heading warning in the events client by inserting visually hidden fallback text inside headings wrapping pulsing skeleton loaders.

## ⚡ Performance & Transition Optimizations

- 🔄 **Refined Transitions**: Replaced general `transition-all` classes with standard `transition` classes in the Navbar and modal components to limit animations to standard visual properties and prevent expensive layout reflows.
- ⏱️ **Fast Array Lookups**: Replaced linear array lookup operations inside loops within modal components with highly efficient `Set` / `Map` lookups, minimizing rendering overhead.

## 🛠️ Code Quality & React Warning Fixes

- 🔑 **Stable Star Rating Keys**: Fixed the `no-array-index-as-key` linter warning in the `StarRating` component by using stable, module-scoped values instead of array indices.
- 🌐 **Consistent Metadata URLs**: Resolved metadata URL consistency warnings in Next.js by adopting relative paths for openGraph and canonical URLs.
- 🧪 **Impure State Updater**: Corrected an impure state updater pattern within the Navbar component to align with React's best practices.
- 📝 **v3.0.0 Release Documentation**: Added the release blog posts for Jorbites v3.0.0 in English, Spanish, and Catalan.
