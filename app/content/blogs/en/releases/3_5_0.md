# 🚀 Jorbites v3.5.0 is here!

We are excited to announce the release of Jorbites v3.5.0! This release brings major updates to course certificates with database verification, CMS content submission tools, new leftover events, draft courses, and UI improvements for recipe handling.

## ✨ Course Certificates & Verification

- 📜 **Database Source of Truth**: Added database verification and LinkedIn credential sharing for course certificates.
- 🎓 **Drafts Course**: Added dedicated course module for drafts management.

## 🍽️ Recipe & Event Improvements

- 🥘 **Leftover Event**: Introduced a new recipes leftover event to minimize food waste.
- 🔍 **Recipe Not Found View**: Improved display and user experience when a requested recipe is not found.
- 🔄 **Missing ID Handling**: Resolved page refresh issues when a recipe ID is missing or invalid.
- 🚚 **Event Content Migration**: Migrated events content to streamline event data management.

## 🛠️ CMS & Content Syncing

- 📤 **CMS Content Submission**: Added content submission buttons for events and blogs, deprecating manual workflow steps.
- 🔄 **Content & Blog Sync**: Added `sync:content` and `sync:blogs` scripts preserving releases and updates.

## 📦 Dependencies & Documentation

- 📦 **Dependency Updates**: Bumped Next.js to `16.3.8`, Axios to `1.20.0`, and `i18next-http-backend` to `4.0.2`.
- 📖 **v3.4.3 Documentation**: Included release notes for Jorbites v3.4.3 across all languages.
