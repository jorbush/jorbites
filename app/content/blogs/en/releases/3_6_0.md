# 🚀 Jorbites v3.6.0 is here!

We are excited to announce the release of Jorbites v3.6.0! This release introduces the Cooksnap feature for sharing recipe photos and feedback, major profile enhancements including bio and social links, customizable profile display settings, multi-language event notifications, and core dependency updates.

## 📸 Cooksnaps

- 📷 **Cooksnap Feature**: Added Cooksnap functionality complete with submission modal, photo gallery, and notification triggers.
- 📝 **Detailed Cooksnap Views**: Display full user notes and author details directly in Cooksnap cards and views.

## 👤 Enhanced User Profiles

- 🌐 **Bio, Website & Social Links**: Users can now enrich their profile with a bio, personal website, and social media links.
- ⚙️ **Customizable Display Settings**: Added display toggles in settings to show or hide profile statistics and contribution graphs.
- 📑 **Profile Navigation & States**: Renamed profile tab to "Blogs", removed tab counts for a cleaner UI, and improved empty state feedback.
- 🛠️ **Refactored Profile Page**: Optimized internal component structure to reduce control-flow complexity.

## 🔔 Notifications & CI Workflows

- 🌐 **Multi-Language Event Notifications**: Added support for sending event notifications in multiple languages.
- ⚙️ **Workflow & CI Updates**: Updated blog release notifications with manual triggers and upgraded Cypress E2E testing action.

## 📦 Dependencies & Documentation

- 📦 **Dependency Updates**: Upgraded Next.js to `16.4.1` and Vite to `6.4.4`.
- 📖 **v3.5.0 Documentation**: Added release blog posts for Jorbites v3.5.0.
