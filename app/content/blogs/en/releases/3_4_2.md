# 🚀 Jorbites v3.4.2 is here!

We are excited to announce the release of Jorbites v3.4.2! This patch release introduces real user avatars in draft cards, adds the Vuelta en Bocatas event, updates English translations for meal planning, upgrades Next.js and TypeScript, cleans up unused exports, and updates documentation.

## ✨ Features & Enhancements

- 👥 **Real User Avatars in Draft Cards**: Added display of actual user avatars inside draft cards.
- 🥪 **Vuelta en Bocatas Event**: Added the new "Vuelta en Bocatas" event.
- 🌐 **Terminology Update**: Renamed "Meal Planner" to "Plannings" for English locale.

## 🐛 Code Quality & Maintenance

- 🛠️ **Unused Export Removal**: Removed unused default export in `useBiteCardGesture` hook.
- ⬆️ **Dependency Upgrades**: Upgraded Next.js and TypeScript dependencies.

## 📖 Documentation

- 📖 **v3.4.1 Documentation**: Added release blog post for Jorbites v3.4.1 across all supported languages.
