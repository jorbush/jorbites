# 🚀 Jorbites v3.2.3 is here!

We are excited to announce the release of Jorbites v3.2.3! This update brings UI component improvements, React hook optimizations and warning fixes, hydration guard enhancements, and architecture diagram updates.

## 🎨 UI & Component Improvements

- 👥 **RecipeModal Share Icon**: Updated the share link icon in `RecipeModal` to `FaUserPlus` to better represent collaboration and sharing.
- 🛡️ **Client-Side Guarding**: Wrapped recipe edit and delete buttons in `ClientOnly` to prevent hydration mismatches and ensure smooth client rendering.

## ⚡ React Optimizations & Fixes

- ⏳ **Suspense Boundary**: Wrapped `useSearchParams` in a `Suspense` boundary inside `RecipeModal` to optimize Next.js client-side rendering.
- 🛠️ **Hook & Linter Fixes**: Resolved the `no-pass-data-to-parent` review warning and addressed `exhaustive-deps` warning in `useRecipeLock`.

## 📖 Documentation & Architecture

- 📐 **Diagram Update**: Updated R2 architecture diagram.
- 📝 **v3.2.2 Release Notes**: Added release blog posts for Jorbites v3.2.2 in English, Spanish, and Catalan.
