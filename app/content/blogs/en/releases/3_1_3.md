# 🚀 Jorbites v3.1.3 is here!

We are excited to announce the release of Jorbites v3.1.3! This update focuses on fixing warnings related to JSON parsing and async operations, translating system messages, improving automated Jest mock tests, and introducing documentation for our previous release.

## 🛠️ Bug Fixes & Code Quality

- 🧹 **JSON Parsing**: Fixed JSON parse warnings.
- 🔄 **useEffect Async Operations**: Corrected an await warning inside `useEffect` hook.
- 🧪 **Jest Tests**: Improved Jest mock test configurations and structure.
- 🗣️ **Translations**: Resolved localized translation keys.

## 📝 Documentation & Releases

- 📖 **v3.1.2 Documentation**: Added the release blog posts for Jorbites v3.1.2 in English, Spanish, and Catalan.
