# 🚀 Jorbites v3.1.0 is here!

We are pleased to announce the release of Jorbites v3.1.0! This update brings highly requested additions, focusing on recipe visual enhancements and more customizable Gantt charts.

## 📊 New Features & Enhancements

- 🍽️ **Recipe Tables**: Added dedicated tables inside recipes to structure and organize ingredients, steps, or custom info more cleanly.
- 📅 **Gantt Options**: Introduced rich customizable options for Gantt charts, allowing for interactive and dynamic timeline adjustments.
