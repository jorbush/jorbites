# 🚀 Jorbites v3.3.0 is here!

We are excited to announce the release of Jorbites v3.3.0! This release introduces support for multiple draft recipes, our roadmap through the end of 2026, mobile display and tooltip interaction improvements, list step parsing enhancements, and updated dependencies.

## ✨ New Features & Roadmap

- 📝 **Multiple Recipe Drafts**: You can now create, save, and manage multiple recipe drafts simultaneously.
- 🗺️ **Roadmap End 2026**: Published our updated product roadmap outlining upcoming features and plans through the end of 2026.

## 🎨 UI & Mobile Fixes

- 📱 **Calendar Badges Display**: Improved calendar event badges layout and visibility on screens smaller than `md`.
- 💡 **Mobile Tooltip Fix**: Prevented tooltips from remaining stuck or visible after tapping on mobile touch devices.

## 📝 Parsing & Maintenance

- 📋 **List Steps Parsing**: Improved step and list parsing logic for structured recipe content.
- 📦 **Dependency Updates**: Updated project dependencies to the latest versions.
- 📖 **v3.2.4 Documentation**: Published release blog posts for Jorbites v3.2.4 across all supported languages.
