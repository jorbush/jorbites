# 🚀 Jorbites v3.4.3 is here!

We are excited to announce the release of Jorbites v3.4.3! This patch release focuses on performance improvements through mobile image optimizations, component modularization by extracting recipe steps components, code quality fixes for React exhaustive dependencies and React Doctor issues, and documentation updates.

## ✨ Features & Performance Optimizations

- 🖼️ **Image Optimization**: Optimized images across the application, with specific enhancements for mobile devices to boost loading speed and performance.
- 🧩 **Recipe Steps Components**: Extracted recipe steps into dedicated components for improved maintainability and reusability.

## 🐛 Code Quality & Fixes

- ⚛️ **React Exhaustive Dependencies Warning**: Resolved React hooks exhaustive dependencies warning.
- 🩺 **React Doctor Issues**: Fixed missing React Doctor code health issues across the codebase.

## 📖 Documentation

- 📖 **v3.4.2 Documentation**: Added release blog post for Jorbites v3.4.2 across all supported languages.
