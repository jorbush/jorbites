# 🚀 Jorbites v2.9.0 is here!

We are excited to announce the release of Jorbites v2.9.0! This release brings major new features, including Bite Cards, advanced granular notification preferences, and a suite of performance and UI enhancements.

## ✨ What's new

- 🃏 **Bite Cards**: Introducing Bite Cards! Share, browse, and interact with quick, delightful recipe bites directly in the app.
- 🔔 **Granular Notification Management**: Gain full control over your alerts. We have introduced granular settings so you can customize exactly which notifications you receive, with a polished and reliable UI state.

## 🛠️ Technical Improvements

- ⚡ **Performance & Code Quality**:
    - Eliminated sequential await waterfalls in the bite cards page to ensure fast, parallelized data loading.
    - Resolved `js-flatmap-filter` warnings in the bite-cards route and `js-tosorted-immutable` warnings in `getBiteCards.ts` to implement cleaner, more efficient array operations.
- 🎨 **UI, Styling & Accessibility**:
    - Addressed `design-no-bold-heading` warnings in BiteCard components to ensure beautiful typography.
    - Fixed gray text contrast on colored backgrounds, enhancing overall accessibility.
    - Resolved React `no-event-handler` warnings to improve event synchronization.
- 📦 **Dependency Updates**: Upgraded `postcss` from 8.5.12 to 8.5.18 for security and rendering performance.
