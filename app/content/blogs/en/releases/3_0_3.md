# 🚀 Jorbites v3.0.3 is here!

We are pleased to announce the release of Jorbites v3.0.3! This update focuses on upgrading dependencies for security, resolving reference/rendering errors in React components, and adding documentation for the previous release.

## 🛠️ Security & Code Quality

- 🔒 **PostCSS Security Update**: Bumped `postcss` from `8.5.18` to `8.5.23` to address dependency vulnerabilities.
- ⚛️ **React Ref Errors**: Fixed ref assignment/rendering errors to prevent state synchronization and hook reference warnings.

## 📝 Documentation & Releases

- 📖 **v3.0.2 Release Documentation**: Added the release blog posts for Jorbites v3.0.2 in English, Spanish, and Catalan.
