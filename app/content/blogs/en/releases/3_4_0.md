# 🚀 Jorbites v3.4.0 is here!

We are excited to announce the release of Jorbites v3.4.0! This feature release introduces draft invite modal management, user navigation menu updates for drafts, a new Chilean recipes event, end-to-end test coverage for plannings and lists, UI design warning resolutions, and dependency updates.

## ✨ New Features & Navigation

- ✉️ **Draft Invite Modal Management**: Added management options for draft invitation modals.
- 👤 **User Menu Navigation**: Reordered user menu to place "My Drafts" directly below "My Profile".
- 🇨🇱 **Chilean Recipes Event**: Introduced a new culinary event dedicated to Chilean recipes.

## 🧪 Testing & Code Quality

- 🧪 **E2E Testing**: Added comprehensive end-to-end tests for planning and list workflows.
- 🐛 **React Destructuring Fix**: Resolved destructuring issues when handling multiple recipe drafts.
- 🎨 **DraftCard Design Warning**: Fixed `no-gray-on-colored-background` warning in `DraftCard`.

## 📦 Dependencies & Documentation

- 📦 **Vitest Update**: Bumped `vitest` to version `4.1.11`.
- 📖 **v3.3.1 Documentation**: Added release blog post for Jorbites v3.3.1 across all supported languages.
