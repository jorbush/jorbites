# 🚀 ¡Jorbites v3.6.0 ya está aquí!

¡Nos complace anunciar el lanzamiento de Jorbites v3.6.0! Esta versión introduce la funcionalidad Cooksnap para compartir fotografías e impresiones de recetas, importantes mejoras en el perfil de usuario incluyendo biografía y redes sociales, ajustes personalizables de visualización del perfil, notificaciones de eventos multilingües y actualizaciones de dependencias clave.

## 📸 Cooksnaps

- 📷 **Funcionalidad Cooksnap**: Añadida la experiencia de Cooksnap con modal de envío, galería de fotos y sistema de notificaciones.
- 📝 **Vista detallada de Cooksnap**: Muestra notas completas del usuario y detalles del autor en las tarjetas e impresiones de Cooksnap.

## 👤 Mejoras en el perfil de usuario

- 🌐 **Biografía, sitio web y redes sociales**: Los usuarios ahora pueden enriquecer su perfil añadiendo una biografía, sitio web personal y enlaces a redes sociales.
- ⚙️ **Ajustes de visualización personalizables**: Añadidos conmutadores en los ajustes para mostrar u ocultar las estadísticas del perfil y el gráfico de contribuciones.
- 📑 **Navegación y estados del perfil**: Se renombró la pestaña a "Blogs", se eliminaron los contadores para una interfaz más limpia y se mejoraron las vistas de estado vacío.
- 🛠️ **Refactorización del perfil**: Optimizada la estructura interna de componentes para reducir la complejidad del flujo de control.

## 🔔 Notificaciones y flujos CI

- 🌐 **Notificaciones de eventos multilingües**: Añadido soporte para enviar notificaciones de eventos en múltiples idiomas.
- ⚙️ **Actualización de flujos de trabajo**: Actualizadas las notificaciones de lanzamientos con activadores manuales y actualizada la acción de pruebas Cypress.

## 📦 Dependencias y documentación

- 📦 **Actualización de dependencias**: Se actualizó Next.js a `16.4.1` y Vite a `6.4.4`.
- 📖 **Notas de versión v3.5.0**: Se incluyeron las entradas de blog del lanzamiento de Jorbites v3.5.0.
