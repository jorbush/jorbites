# 🚀 ¡Jorbites v3.1.2 ya está aquí!

¡Nos complace anunciar el lanzamiento de Jorbites v3.1.2! Esta actualización se centra en resolver varios problemas de diseño, mejorar la accesibilidad, optimizar la inicialización del estado de planificación, prevenir posibles fugas de memoria y limpiar exportaciones no utilizadas.

## 🛠️ Calidad de código y correcciones

- ♿ **Accesibilidad y rejilla Gantt**: Se corrigió la advertencia de accesibilidad en `RecipeGanttGrid`.
- 📐 **Estilos de Tailwind**: Se resolvieron varias advertencias de `design-no-redundant-size-axes` en diversos componentes.
- 🧹 **Exportaciones no utilizadas**: Se eliminaron las exportaciones predeterminadas no utilizadas de los archivos de `RecipeGantt` para mantener las importaciones limpias.
- 🔄 **Manejadores de eventos**: Se corrigió el problema con el proxy de manejadores de eventos.
- 💾 **Prevención de fugas de memoria**: Se revocó la URL del objeto en el modal de exportación del calendario, asegurando que los recursos del navegador se liberen correctamente.
- ⚡ **Optimización de estado**: Se optimizó la inicialización del estado `isSaved` dentro del hook `usePlanningState` para un mejor rendimiento.
- 🖼️ **Relación de aspecto del logo**: Se corrigió la relación de aspecto del logo para evitar la distorsión de elementos visuales.

## 📝 Documentación y lanzamientos

- 📖 **Documentación de v3.1.1**: Se agregó la publicación de blog de lanzamiento de Jorbites v3.1.1.
