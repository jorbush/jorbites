# 🚀 ¡Jorbites v2.9.0 ya está aquí!

¡Nos complace anunciar el lanzamiento de Jorbites v2.9.0! Esta versión trae importantes novedades, como las Bite Cards, preferencias avanzadas de notificación granular, y una serie de mejoras de rendimiento y de interfaz de usuario.

## ✨ ¿Qué hay de nuevo?

- 🃏 **Bite Cards**: ¡Presentamos las Bite Cards! Comparte, explora e interactúa con bocados rápidos y encantadores de recetas directamente en la aplicación.
- 🔔 **Gestión granular de notificaciones**: Obtén un control total sobre tus alertas. Hemos introducido configuraciones granulares para que puedas personalizar exactamente qué notificaciones recibes, con un estado de interfaz de usuario pulido y confiable.

## 🛠️ Mejoras técnicas

- ⚡ **Rendimiento y calidad del código**:
    - Se eliminaron las esperas secuenciales (sequential await waterfalls) en la página de bite cards para garantizar una carga de datos rápida y simultánea.
    - Se resolvieron las advertencias de `js-flatmap-filter` en la ruta de bite-cards y las advertencias de `js-tosorted-immutable` en `getBiteCards.ts` para implementar operaciones de matriz más limpias y eficientes.
- 🎨 **Interfaz de usuario, diseño y accesibilidad**:
    - Se corrigieron las advertencias de `design-no-bold-heading` en los componentes BiteCard para garantizar una tipografía armoniosa.
    - Se solucionaron los problemas de contraste de texto gris sobre fondos de color, mejorando la accesibilidad general.
    - Se resolvieron las advertencias de React `no-event-handler` para mejorar la sincronización de eventos.
- 📦 **Actualización de dependencias**: Actualizado `postcss` de 8.5.12 a 8.5.18 para mejorar la seguridad y el rendimiento de renderizado.
