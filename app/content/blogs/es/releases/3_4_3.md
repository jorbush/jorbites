# 🚀 ¡Jorbites v3.4.3 ya está aquí!

¡Nos complace anunciar el lanzamiento de Jorbites v3.4.3! Esta versión se centra en mejoras de rendimiento mediante la optimización de imágenes para dispositivos móviles, la modularización de componentes extrayendo los pasos de recetas, correcciones de calidad de código para dependencias exhaustivas de React, resolución de incidencias de React Doctor y actualizaciones de documentación.

## ✨ Funciones y optimizaciones de rendimiento

- 🖼️ **Optimización de imágenes**: Se optimizaron las imágenes en toda la aplicación, con mejoras específicas para dispositivos móviles para mejorar la velocidad de carga y el rendimiento.
- 🧩 **Componentes de pasos de receta**: Se extrajeron los pasos de receta en componentes dedicados para mejorar la mantenibilidad y reutilización.

## 🐛 Calidad de código y correcciones

- ⚛️ **Aviso de dependencias exhaustivas de React**: Se resolvió el aviso de dependencias exhaustivas en hooks de React.
- 🩺 **Incidencias de React Doctor**: Se corrigieron las incidencias detectadas por React Doctor en la base de código.

## 📖 Documentación

- 📖 **Notas de versión v3.4.2**: Se agregaron las entradas de blog del lanzamiento de Jorbites v3.4.2 en todos los idiomas compatibles.
