# 🚀 ¡Jorbites v3.5.0 ya está aquí!

¡Nos complace anunciar el lanzamiento de Jorbites v3.5.0! Esta versión trae actualizaciones importantes para los certificados de cursos con verificación en base de datos, herramientas de envío de contenido en el CMS, nuevos eventos de aprovechamiento de sobras, cursos de borradores y mejoras de interfaz en la gestión de recetas.

## ✨ Certificados de cursos y verificación

- 📜 **Fuente de verdad en base de datos**: Se añadió verificación en base de datos y compartir credenciales en LinkedIn para los certificados de cursos.
- 🎓 **Curso de borradores**: Se añadió un módulo de curso dedicado a la gestión de borradores.

## 🍽️ Mejoras en recetas y eventos

- 🥘 **Evento de sobras**: Se introdujo un nuevo evento de recetas de aprovechamiento para reducir el desperdicio de comida.
- 🔍 **Vista de receta no encontrada**: Se mejoró la visualización y experiencia cuando no se encuentra una receta solicitada.
- 🔄 **Gestión de ID faltante**: Se resolvieron los problemas de recarga cuando falta o no es válido el ID de una receta.
- 🚚 **Migración de contenido de eventos**: Se migró el contenido de eventos para optimizar la gestión de datos.

## 🛠️ CMS y sincronización de contenido

- 📤 **Envío de contenido CMS**: Se añadieron botones de envío de contenido para eventos y blogs, marcando como obsoletos los métodos anteriores.
- 🔄 **Sincronización de contenido y blogs**: Se añadieron los comandos `sync:content` y `sync:blogs` preservando publicaciones y actualizaciones.

## 📦 Dependencias y documentación

- 📦 **Actualización de dependencias**: Se actualizó Next.js a `16.3.8`, Axios a `1.20.0` e `i18next-http-backend` a `4.0.2`.
- 📖 **Notas de versión v3.4.3**: Se incluyeron las entradas de blog del lanzamiento de Jorbites v3.4.3 en todos los idiomas.
