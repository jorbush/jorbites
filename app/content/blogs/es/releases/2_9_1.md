# 🚀 ¡Jorbites v2.9.1 ya está aquí!

¡Nos complace anunciar el lanzamiento de Jorbites v2.9.1! Esta versión se enfoca principalmente en la auditoría de seguridad, el refuerzo de la base de datos, la protección de las APIs y la refactorización de código para mantener Jorbites rápido, seguro y moderno.

## 🔒 Seguridad y refuerzo de sistemas

- 🔑 **Seguridad en el restablecimiento de contraseñas**: Se reforzó el almacenamiento de la base de datos mediante el hashing seguro con SHA-256 de los tokens de restablecimiento de contraseña antes de realizar cualquier consulta o actualización en Prisma.
- 🛡️ **Control de acceso y seguridad de APIs**:
    - Se protegió el endpoint GET de Planning con controles de acceso privados estrictos para evitar la exposición no autorizada de datos.
    - Se implementó una solución robusta para el proxy de imágenes para eliminar las vulnerabilidades de falsificación de solicitudes del lado del servidor (SSRF).
    - Se agregaron límites de tarifa (rate limits) adicionales en los endpoints para prevenir abusos e intentos de denegación de servicio.
- 🍪 **Refuerzo de sesiones y configuración**:
    - Se configuraron ajustes explícitos de sesión de NextAuth (`maxAge` y `updateAge`) y se podaron las reclamaciones JWT no utilizadas para asegurar y minimizar las cookies de los clientes.
    - Se inyectaron encabezados de seguridad Strict-Transport-Security (HSTS) y una Permissions-Policy restrictiva en `next.config.js`.
    - Se movió la configuración del correo de contacto VAPID de forma dinámica a variables de entorno (`VAPID_EMAIL`) con prefijado automático de esquema mailto.
- 📝 **Auditoría de seguridad y legal**: Se completó la auditoría de seguridad integral de Jorbites para 2026 y se actualizaron los Términos y Condiciones para reflejar los últimos estándares de seguridad.

## 🛠️ Mejoras técnicas y optimización

- ⚡ **Rendimiento de React y Next.js**:
    - Se desestructuraron métodos como `push` de `useRouter` para optimizar los gráficos de dependencias y facilitar la memorización del React Compiler.
    - Se resolvieron las advertencias de estado derivado y gestión de eventos de React en `NotificationPreferencesManager` para evitar renderizados innecesarios.
    - Se reemplazaron los bucles de arrays O(n) con un `Set` de búsqueda estático dentro de la lógica PATCH de preferencias de notificación, logrando pruebas de pertenencia eficientes O(1).

## 🎨 Interfaz de usuario, diseño y movimiento

- 🌊 **Transición de flotación suave**: Se reemplazaron las animaciones de rebote (bounce) obsoletas con una transición de desaceleración flotante suave altamente profesional y personalizada en los elementos de carga y de acción.
- 📐 **Simplificación de Tailwind**: Se adoptó la clase abreviada moderna `size-4` de Tailwind v3.4+ para reemplazar los ejes redundantes de ancho (width) y alto (height).
