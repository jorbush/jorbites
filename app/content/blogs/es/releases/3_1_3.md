# 🚀 ¡Jorbites v3.1.3 ya está aquí!

¡Nos complace anunciar el lanzamiento de Jorbites v3.1.3! Esta actualización se centra en corregir advertencias relacionadas con el análisis de JSON y operaciones asíncronas, traducir mensajes del sistema, mejorar las pruebas de mock automatizadas con Jest e introducir documentación de nuestro lanzamiento anterior.

## 🛠️ Correcciones de errores y calidad de código

- 🧹 **Análisis JSON**: Se corrigieron las advertencias de análisis JSON.
- 🔄 **Operaciones asíncronas en useEffect**: Se corrigió una advertencia de await dentro del hook `useEffect`.
- 🧪 **Pruebas de Jest**: Se mejoró la configuración y estructura de las pruebas de mock de Jest.
- 🗣️ **Traducciones**: Se resolvieron claves de traducción localizadas.

## 📝 Documentación y lanzamientos

- 📖 **Documentación de v3.1.2**: Se agregaron las publicaciones de blog de lanzamiento para Jorbites v3.1.2 en catalán, español e inglés.
