# 🚀 ¡Jorbites v3.0.0 ya está aquí!

¡Nos complace anunciar el lanzamiento de Jorbites v3.0.0! Esta versión marca un hito importante al introducir categorías de seguimiento de tiempo más precisas, controles robustos para las políticas de contraseñas, mejoras clave en las APIs y correcciones críticas en la gestión del estado para asegurar una experiencia de usuario más fluida y confiable.

## ⏱️ Mejor distinción del tiempo

- 📅 **Diferenciación de tiempos**: Se aclaró y refinó cómo se definen y muestran los tiempos de preparación, cocción y total en toda la plataforma, facilitando la planificación de las sesiones culinarias para los cocineros en casa.

## 🔒 Seguridad y refuerzo de APIs

- 🛡️ **Política de contraseñas segura**: Se fortaleció la seguridad de las cuentas de usuario implementando una política de contraseñas más robusta, protegiendo las credenciales contra las amenazas de seguridad modernas.
- 🔄 **Semántica de API RESTful**: Se actualizó la ruta de subida de imágenes de usuario, cambiando el método HTTP de `PUT` a `PATCH` para alinearse con los estándares RESTful adecuados para actualizaciones parciales de recursos.

## 🛠️ Mejoras técnicas y correcciones de errores

- ⚡ **Corrección de estado derivado (No-Derived-State)**: Se corrigió un error de gestión de estado en el formulario de creación y edición de recetas donde el estado derivado causaba comportamientos inesperados en la interfaz de usuario o renderizados adicionales.
- 📝 **Documentación del lanzamiento de v2.9.1**: Se publicaron formalmente las entradas de blog de lanzamiento para Jorbites v2.9.1 en inglés, español y catalán.
