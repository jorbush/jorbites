# 🚀 ¡Jorbites v3.0.3 ya está aquí!

¡Nos complace anunciar el lanzamiento de Jorbites v3.0.3! Esta actualización se centra en actualizar las dependencias por seguridad, resolver errores de referencia/renderizado en componentes de React y agregar documentación para el lanzamiento anterior.

## 🛠️ Seguridad y calidad de código

- 🔒 **Actualización de seguridad de PostCSS**: Se actualizó `postcss` de `8.5.18` a `8.5.23` para abordar vulnerabilidades en las dependencias.
- ⚛️ **Errores de referencias de React**: Se corrigieron errores de asignación/renderizado de referencias (ref) para evitar advertencias de sincronización de estado y referencias de hooks.

## 📝 Documentación y lanzamientos

- 📖 **Documentación del lanzamiento de v3.0.2**: Se agregaron las publicaciones de blog de lanzamiento de Jorbites v3.0.2 en inglés, español y catalán.
